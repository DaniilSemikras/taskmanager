# Task Manager

Задачник для команды: доска, календарь встреч, нотатки, участники, команды, сводка и роли пользователей.

## Запуск на компьютере

1. Установите Node.js 18 или новее.
2. Запустите `node server.js` или дважды нажмите `Запустить Task Manager.bat`.
3. Откройте `http://127.0.0.1:3000`.

Стартовый доступ: `admin` / `admin`. Сразу после входа смените его через админ-панель.

Все рабочие данные автоматически хранятся в `taskmanager-data.json`. Этот файл специально не добавляется в Git, чтобы задачи, встречи, контакты и пароли не попадали в публичный репозиторий.

## Публикация

GitHub хранит исходный код проекта. GitHub Pages не может запустить `server.js` и не подходит для общего хранения данных. Для доступной в интернете версии подключите репозиторий к хостингу Node.js (например, Render или Railway) и добавьте постоянное хранилище данных.
